# Workout keyboard controls

On Train, press **Enter** or **Space** to record the next set and start rest. While rest is running, either key pauses it; another press resumes it. These keys keep controlling the current exercise after clicking Previous/Next or using the arrow keys, even when an exercise navigation button has focus. **Left arrow** and **Right arrow** move between exercises without changing recorded sets or rest timers. Navigation stops at either end of the workout.

Shortcuts leave number fields, selects, editable text, dialogs and other app views alone. Enter/Space on a deliberately focused settings button, link, disclosure or other control keep their normal action. Held keys do not repeat workout shortcuts, and Space does not scroll or trigger a second action on release. Modified keys keep their browser behavior. Tab still moves through the normal controls; the action/navigation buttons expose their shortcuts to assistive technology.

Both exercise navigation cards show the neighboring exercise's current setup angle, including 0°, or “Angle not set.” This comes from the workout snapshot so historical angle settings remain accurate.
